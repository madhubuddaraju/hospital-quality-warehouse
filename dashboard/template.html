    Hospitals to watch

    Hospitals Medicare rates significantly worse than the national rate on two or more patient outcomes (deaths, readmissions, complications, infections), or whose star rating fell sharply during the past year (by two stars or more, or down to one star).

    How it's built

    A weekly pipeline downloads six Medicare datasets, models them with dbt in DuckDB, tests every layer and publishes this page. Dagster orchestrates it; every dbt test is a Dagster asset check, so a failed check stops a bad release from reaching the page.

    1. Ingest: the current release of each dataset from the CMS Provider Data Catalog API, ZIP code centroids from the Census Bureau, and every past release since 2021 from the CMS archive API.
    2. Stage: one view per source fixes types, US-format dates, the literal text "Not Available", and six different spellings of "better/worse than national".
    3. Model: all measures stacked into one table, each hospital benchmarked against every other, then reason scores, a watch list and state summaries. The marts have enforced contracts.
    4. History: releases replayed oldest first through a dbt snapshot, so each rating version carries the date of the release it came from.
    5. Test: schema tests, custom tests and dbt unit tests for the cleaning and ranking logic run on every build and in CI.
